# 🌍 GlobalTraveler - Hackathon Project

GlobalTraveler is a full-stack PHP + MySQL web application designed for planning, managing, and tracking trips.  
It provides user registration/login, trip creation, itinerary building, budget tracking, and regional recommendations.

---

## ✨ Features

- **User Authentication**
  - Register with validation (email, phone, password rules).
  - Secure login with hashed passwords.
  - Session-based dashboard access.

- **Dashboard**
  - Profile card with user details (city, country).
  - Trips categorized by status: Planned, Ongoing, Completed.
  - Quick access to itineraries.
  - **Create Trip** button for logged-in users.

- **Trip Management**
  - Create new trips with destination, dates, notes, and cover photo.
  - View trips by status.
  - Itinerary builder with stops and activities.

- **Budget Tracking**
  - Add planned vs. actual expenses per category (transport, food, accommodation, etc.).
  - Summarized budget view for each trip.

- **Regional Recommendations**
  - Homepage shows top regions with images and descriptions.
  - Encourages exploration and trip inspiration.

- **Extras**
  - Reviews & ratings for trips.
  - Forgot password flow.
  - Responsive design with modern UI.

---

## 🛠️ Tech Stack

- **Backend:** PHP (procedural + MySQLi prepared statements)
- **Frontend:** HTML, CSS, JavaScript (jQuery for dynamic dropdowns)
- **Database:** MySQL
- **Server:** XAMPP / Apache
